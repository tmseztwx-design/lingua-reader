# Scribe · AI 英语专著精读学习平台

一个以英语专业文献深度阅读为核心的本地 MVP。它把文献项目、双语精读、语境词卡、笔记、间隔复习、学习计时、数据分析和本地数据导出连接在一个浏览器工作区中。

## 项目结构

- `index.html`：精读主应用入口（单页，原生 JS + 内联样式）
- `mobile.html`：手机上传页（Vite 第二入口；一套队列 UI，云通道与本机通道共用）
- `src/mobile-upload.js`：手机上传页逻辑与两种传输通道
- `src/cloud-bridge.js`：把 Enter 云客户端与二维码生成器挂到 `window`，供页面上原有的经典脚本调用
- `src/integrations/supabase/`：框架生成的云端客户端与类型（自动生成，不要手改）
- `supabase/functions/`：后端函数（`scribe-mobile-upload` 上传中转、`scribe-ocr` 云端识别）
- `public/`：静态资源（`import-queue.js` 电脑端队列、`favicon.svg`）
- `vite.config.ts`：开发服务器配置（Vite，端口 8080，含 Enter 平台插件）
- `server.mjs`：本机服务（局域网扫码通道、原页存取、本机 OCR 调度），端口 4174
- `ocr.swift`：调用 macOS Vision 的逐页文字识别脚本
- `dist/`：构建产物，由 `pnpm build` 生成（已加入 `.gitignore`）

## 本地运行

### 1. 网页预览与开发（工作区预览用的就是这个）

    pnpm install
    pnpm dev

打开 http://localhost:8080。此模式由 Vite 提供静态页面，不含本机 OCR 与手机直传接口，其余书库、精读、学习卡、复习、数据等功能全部可用。

### 2. 完整本机能力（OCR 与手机直传）

    pnpm build
    pnpm start

打开 http://localhost:4174。本条通道的手机直传、原页清理和本机 OCR 需要此本地服务，不要只用静态文件服务器打开 `dist`。云通道不需要它。

## 两条手机上传通道

「导入文献」面板里可以切换，选择会被记住：

| 通道 | 网络要求 | 识别位置 | 适合 |
| --- | --- | --- | --- |
| 云端中转 | 手机任意网络（含移动数据） | Enter 云上的 GPT 视觉模型 | 把应用发布出去给其他人用；电脑不必开机 |
| 本机直连 | 手机与电脑同一 Wi‑Fi | 电脑上的 macOS Vision（`ocr.swift`） | 完全离线、文档只留在本机 |

云通道的流程：电脑端生成二维码（内容是「已发布站点地址 + /mobile.html?t=…」，二维码在前端生成，不依赖本机服务）→ 手机扫码后按顺序上传到 Enter 云私有存储 → 云端逐页识别 → 应用把结果写入书库并打开精读页。原页长期保留在云端，也可以在「云端批次」里手动删除。

使用云通道有两点前提：

1. 手机打开的是**已发布站点**的地址，所以需要先发布项目（预览地址会变）。
2. 识别在云端进行，消耗的是**本项目（你）的 AI 额度**：别人用得越多，消耗在你身上。界面上会显示识别页数，方便你控制。

## 已实现的本地闭环

- 书库：项目状态、阅读进度、分类筛选
- 导入：电脑多文件队列、手机两条上传通道、PDF/Word/图片导入与版本化处理步骤展示
- 识别：云通道用 GPT 视觉模型逐页转录原文；本机通道用 macOS Vision 识别
- 精读：英文、点击译文、中英对照；段落页码；词汇点击；划选操作；上下文问答
- 积累：词汇、表达和句子学习卡；可编辑笔记；原文出处
- 复习：显示答案、四档熟悉度、间隔复习排程
- 记录：活跃学习计时、学习结束报告、热力图和周数据
- 数据：浏览器 LocalStorage 持久化、学习卡和完整数据 JSON 导出

## 隐私与边界

学习状态保存在当前浏览器。云通道的原页保存在 Enter 云私有存储（仅凭上传通道 token 签发地址才能读取），本机通道的原页保存在电脑上的本地服务中。

“本机直连”要求手机与电脑连接同一 Wi‑Fi：电脑端在「导入文献」生成二维码后，请用手机扫码并在系统浏览器中打开。这样可绕开微信的一次多图限制，从完整相册多选书页；手机端可调整前后顺序，再按该顺序上传整组文件。

云端识别的已知边界：图片（JPG/PNG）与 PDF 由模型直接读取；旧版 `.doc` 和 HEIC 会给出明确提示要求转格式（iPhone 在网页里选照片通常会自动转成 JPEG）；单批最多 100 个文件、单文件最大 100 MB、单次读取的 PDF 不超过 8 MB。

书库中的文献可移至「最近删除」，30 天内可以恢复。网站打开时及使用期间会检查保留期限，逾期自动永久清理；也可以点击「清空最近删除」并确认后立即清理。永久清理会同时删除该文献由本机服务端保存的原页副本；被其他文献引用的原页不会删除。学习卡独立保留。浏览器关闭期间不会运行后台清理，下次打开网站时执行到期检查。
