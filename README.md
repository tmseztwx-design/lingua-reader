# Scribe · AI 英语专著精读学习平台

一个以英语专业文献深度阅读为核心的本地 MVP。它把文献项目、双语精读、语境词卡、笔记、间隔复习、学习计时、数据分析和本地数据导出连接在一个浏览器工作区中。

## 本地运行

在项目根目录安装依赖并启动本地服务：

    npm install
    npm start

然后打开 http://localhost:4174。手机直传和原页清理需要此本地服务，不要只用静态文件服务器打开 `dist`。

## 已实现的本地闭环

- 书库：项目状态、阅读进度、分类筛选
- 导入：PDF、Word 和常见图片类型的本地导入流程与版本化处理步骤展示
- 精读：英文、点击译文、中英对照；段落页码；词汇点击；划选操作；上下文问答
- 积累：词汇、表达和句子学习卡；可编辑笔记；原文出处
- 复习：显示答案、四档熟悉度、间隔复习排程
- 记录：活跃学习计时、学习结束报告、热力图和周数据
- 数据：浏览器 LocalStorage 持久化、学习卡和完整数据 JSON 导出

## 隐私与边界

学习状态保存在当前浏览器；手机直传的原页副本保存在电脑上的本地服务中。文档处理页的完整流程可用于体验产品闭环；生产级的 PDF/OCR、版面恢复和全文翻译需要在“设置 → AI 服务”连接经过验证的后端处理服务，避免错误宣称浏览器已经实现了专业 OCR。

“手机直传”要求手机与电脑连接同一 Wi‑Fi：电脑端在「导入文献」生成二维码后，请用手机系统相机扫码并在系统浏览器中打开。这样可绕开微信的一次多图限制，从完整相册多选书页；手机端可调整前后顺序，再按该顺序上传整组文件。二维码为一次性本地通道，15 分钟后自动失效；桌面端会将整组文件自动放入同一处理队列，只需一次点击处理。电脑原有拖放和选择文件上传仍可用。

书库中的文献可移至「最近删除」，30 天内可以恢复。网站打开时及使用期间会检查保留期限，逾期自动永久清理；也可以点击「清空最近删除」并确认后立即清理。永久清理会同时删除该文献由本机服务端保存的原页副本；被其他文献引用的原页不会删除。学习卡独立保留。浏览器关闭期间不会运行后台清理，下次打开网站时执行到期检查。
