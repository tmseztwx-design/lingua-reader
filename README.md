# Scribe · AI 英语专著精读学习平台

一个以英语专业文献深度阅读为核心的本地 MVP。它把文献项目、双语精读、语境词卡、笔记、间隔复习、学习计时、数据分析和本地数据导出连接在一个浏览器工作区中。

## 本地运行

在项目根目录启动静态文件服务器：

    python3 -m http.server 4173 --directory dist

然后打开 http://localhost:4173。

## 已实现的本地闭环

- 书库：项目状态、阅读进度、分类筛选
- 导入：PDF、Word 和常见图片类型的本地导入流程与版本化处理步骤展示
- 精读：英文、点击译文、中英对照；段落页码；词汇点击；划选操作；上下文问答
- 积累：词汇、表达和句子学习卡；可编辑笔记；原文出处
- 复习：显示答案、四档熟悉度、间隔复习排程
- 记录：活跃学习计时、学习结束报告、热力图和周数据
- 数据：浏览器 LocalStorage 持久化、学习卡和完整数据 JSON 导出

## 隐私与边界

这是不依赖服务端的可操作 MVP，学习状态保存在当前浏览器。文档处理页的完整流程可用于体验产品闭环；生产级的 PDF/OCR、版面恢复和全文翻译需要在“设置 → AI 服务”连接经过验证的后端处理服务，避免错误宣称浏览器已经实现了专业 OCR。

## 本地运行

安装依赖后运行 `npm start`，在电脑打开 `http://localhost:4174`。

“手机直传”要求手机与电脑连接同一 Wi‑Fi：电脑端在「导入文献」生成二维码，手机使用微信扫码后即可从相册或手机/微信文件选择器直接上传。二维码为一次性本地通道，15 分钟后自动失效；电脑端原有拖放和选择文件上传仍可用。
