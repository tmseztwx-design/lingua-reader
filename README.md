# Scribe · 英语专著精读学习平台

手机和电脑默认把原件上传至 Enter 云私有存储；确认顺序后整批提交，后台逐页识别，结果进入可互动的精读书库。上传期间需要保持上传页打开；原件全部送达并提交后，即使关闭网页或电脑，后台仍会继续。

## 云端书库与跨设备使用

首次打开会为当前设备创建私密云端书库，并迁入本机现有书籍、学习卡和阅读进度。打开设置 → 云端书库 → 显示同步码；在另一台设备选择“连接已有书库”，输入同一同步码。同步码等同于该书库的访问凭证，请妥善保存，不要放进二维码或公开分享。

历史书籍迁入的是信息和已保存文本；旧本机 URL / Blob URL 对应的原件不会自动转成云文件，需要重新提供原文件。新上传的原件直接保存到云端。

同步按书籍、学习卡分别检查版本，旧设备不能静默覆盖新设备；冲突时保留本机副本，可在设置里导出核对。断网操作先保存在本机，联网后继续同步。连接另一书库前保存本机备份；“进入体验”、恢复示例或清空本地数据会开启新工作区，旧云端书库保留，可在设置恢复上一个工作区。

原图地址按需更新。二维码只授予一个批次的访问权限，24 小时上传窗口到期不会删除已导入的文献。手机可用微信扫码、相册多选或拍照；微信自身的选择器可能限制单次选择数量，可多次加入后统一排序。

## 后台处理与删除

数据库保存文件顺序、识别状态、重试次数和工作租约。提交后唤醒后台处理器；每分钟的数据库调度负责恢复中断任务。正常请求只领取未处理页，过期租约可重新领取，迟到结果不能覆盖新任务。失败最多自动尝试三次，原件保留，用户可重试失败页。精读页按确认的队列顺序显示，完成速度不影响页序。

书籍移入最近删除后保留 30 天；恢复会同步到其他设备。“清空最近删除”同步永久删除标记，后台清理原件；过期清理也在云端执行。独立学习卡保留。

## 开发与本机通道

要求 Node.js 22 或更新版本。

    pnpm install
    pnpm dev

开发预览默认端口 8080。云端能力需要先完成下述部署。本机通道可在导入区切换；它仍要求电脑和手机在同一 Wi-Fi，并运行本机服务：

    pnpm build
    pnpm start

本机服务端口 4174，OCR 依赖 macOS Vision。纯静态服务器不包含本机接口。

## Enter 部署顺序

1. 在已连接的 Enter Cloud 上执行迁移 `supabase/migrations/20261003090000_cloud_library_queue.sql`。原来的两张表和私有存储桶保留；新增私密书库、版本记录、工作租约与服务端调度。要求云数据库支持 `pg_cron`、`pg_net`。
2. 生成并部署四个函数：先运行 `pnpm bundle:functions`，再把 `supabase/functions/<name>/index.ts` 逐个部署。**平台只部署这一份入口文件**，同目录与上层的其它 .ts 都不会被带上，所以仓库把可读源放在 `supabase/functions/src/*.ts` 与 `_shared/*.ts`，由脚本内联成自包含的单文件。按照 `supabase/config.toml` 设置；保持现有 AI 服务端密钥。不要把服务角色或 AI 密钥写入前端。每次改动源文件后都要重新生成再部署。
3. 确认 `cron.job` 中 `scribe-background-ocr` 已启用，指向此 Cloud 的 `scribe-queue`。调度凭证生成并保存在 RLS 默认拒绝的表中，仅服务端可读取。
4. 执行 `pnpm test`、`pnpm build` 与 `node test/cloud-live.mjs` 验证真实云端（仅创建合成测试文本，不使用用户文件）。
5. 同步 Enter 项目的代码版本并正式发布。在发布后的 HTTPS 地址生成二维码，再用手机关闭 Wi-Fi、通过微信和移动网络实测。预览环境的访问限制不能代替正式发布验收。

本仓库已连接的 Enter Cloud 已配置完成；若要更换后端，需要同步更新生成的客户端配置、迁移里的后台调度地址，以及已绑定的 AI 项目，并重新部署四个函数。

## 发布

后端就绪后再发布前端：在项目页右上角点「Publish」，构建通过后会得到一个免费的 Enter 域名（可在设置 → 域名里改名）。手机扫码请使用发布后的地址；预览地址会变化，不能用于长期分享。

## 验证与结构

    pnpm test
    pnpm build
    pnpm bundle:functions   # 由 src/ 与 _shared/ 生成可部署的单文件入口

- `index.html`、`mobile.html`：主应用、手机页。
- `src/cloud-library.js`、`src/sync-state.js`：书库同步与设备连接。
- `public/import-queue.js`：电脑文件队列，默认云端、可选本机。
- `scribe-mobile-upload`：批次、签名上传、原件校验与整批提交。
- `scribe-queue`：服务器后台领取、识别、重试与到期清理。
- `scribe-library`：私密书库、版本同步、原页更新。
- `scribe-ocr`：兼容入口，仅入队/重试，不再由浏览器逐页执行识别。
- `supabase/functions/src/*.ts` 与 `supabase/functions/_shared/*.ts`：四个函数的可读源；`<name>/index.ts` 是脚本生成的可部署单文件。

云识别消耗项目 AI 额度。当前支持 JPG/PNG、TXT、DOCX 和 PDF；旧版 DOC、HEIC 仍有格式限制，失败会显示原因并保留原件。单批最多 100 个文件、单文件 100 MB；PDF 模型输入目前限 8 MB，PDF 转录仍以文件为一个阅读单元。OCR 准确度取决于清晰度和版式，不能承诺每页零错误。
