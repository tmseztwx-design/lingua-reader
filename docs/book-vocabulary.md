# 按阅读本隔离词卡，跨书汇总学习

## 使用规则

- 从书库打开阅读本，右侧「本书生词本」只显示这一本的词汇、短语和句子；正文收藏高亮也只依据本书。
- 同一表达在同一本里重复点击不会新增，在不同阅读本里可分别收藏。各自的语境释义、笔记、删除和复习状态互不影响。
- 「知识库」和「复习中心」仍汇总全部阅读本的卡片。跨书的同词卡不合并成一张，避免丢掉不同语境与熟悉程度；显示来源书名，可从知识库回到对应书页。
- 书名可修改，也允许同名书。归属使用稳定的阅读本 ID，不使用标题或当前打开的书名猜测。
- 阅读本进入回收站或被移除时，不自动丢弃已积累的学习卡，也不把它们转给其他书。回到原文需要先恢复对应阅读本。

## 数据兼容

新卡片的 JSON 增加 `documentId`、`documentTitle`（书名快照）、`sourcePageId`、`pageNumber`、`paragraphIndex`。保留原有卡片 ID、笔记、释义和复习字段。`scribe_library_entries` 的 card JSON、云同步以及 JSON 导出/恢复原样保留这些字段，本功能本身不需要 SQL 迁移。

旧卡片优先按原页 ID 或唯一匹配的原文语境归属；也兼容可确认的旧书名来源。早期代码把部分 `source` 写死为示例书名，不能据此把用户卡片全部塞进示例书。无法唯一确认的卡片继续出现在总知识库/总复习中，不出现在任一本的随读列表，可在知识库的「旧卡片归属」中手动选择。

词典缓存按阅读本 ID + 单词 + 上下文分开；查询结果始终按原卡片 ID 写回。换书、乱序响应不会把另一阅读本的释义写进当前卡片。

## 验证与发布

`test/book-cards.test.mjs` 验证跨书隔离、同词独立收藏与删除、分类划选、同名书打开、改名、原页跳转、旧卡兼容与手动归类、异步查词、跨书补全、汇总复习、云同步/备份字段及回收站数据保留。

本地构建：`pnpm build`。这一词卡功能是前端增量，不修改线上文献或数据库。但本 PR 同时包含之前尚未发布的存储/上传升级，**整份 PR 发布仍须遵守 [存储与上传升级清单](storage-upload-upgrade.md)，先备份、迁移与部署后端，再发布前端**，不能只部署页面。
